Keuangan Harian

Tempel Web app URL Apps Script Anda (yang berakhiran /exec).

Lupa URL-nya? Buka editor Apps Script → Deploy → Manage deployments → salin Web app URL.

Dashboard tidak termuat

Halaman Apps Script tidak merespon dalam 10 detik. Penyebab tersering:

1. URL /exec bukan dari deployment yang aktif
2. Deployment belum diperbarui (New version)
3. Izin OAuth belum disetujui setelah scope baru ditambahkan

Buka langsung di browser

Bila "Buka langsung" juga gagal, masalahnya ada di Apps Script (deployment/izin) — bukan di aplikasi ini.
